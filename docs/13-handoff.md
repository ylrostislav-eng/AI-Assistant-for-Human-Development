## Особое внимание

1. Snapshot/ledger ≠ raw client state; awards только server engine.
2. `rescheduled` — ось расписания; не блокирует completion.
3. Same root activity: timer/self-report/device evidence не умножают награду.
4. User sequence под транзакционным lock; cursor не перескакивает через недополученные batches.
5. Mastery сохраняется; игровые последствия Protection заморожены.
6. Условия уровня 100 проверены математически, коэффициенты ещё не откалиброваны реальным пилотом.
7. Точный model ID/библиотека WebRTC/hosting provider пока не выбраны и не проверены; для них есть конкретные задачи, это не скрытые готовые зависимости.
