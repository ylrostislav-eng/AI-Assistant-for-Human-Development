# Миграции backend

Пусто намеренно. Доменные миграции (identity/profile/goals/quests/calendar/sync)
создаются в задаче P1-01, когда закрыты контракты — см. `docs/10-implementation-plan.md`.

Команда применения готова и проверена на временных каталогах в
`services/backend/tests/integration/migrate.test.ts`:

```bash
DATABASE_URL=postgres://... npm run migrate
```

Правила:

- Имя файла задаёт порядок: `NNN_описание.sql`, сортировка по возрастанию имени.
- Применённую миграцию нельзя править — команда сверяет SHA-256 и откажется
  работать. Изменение вносится новой миграцией.
- Каждая миграция и запись о ней применяются в одной транзакции.
